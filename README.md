# Dossiers de soutenance – Titre Professionnel DWWM

Ce dépôt regroupe mes documents de soutenance pour le Titre Professionnel Développeur Web et Web Mobile.
Il ne contient pas le code source du projet (voir le lien plus bas) : il centralise les documents nécessaires à l’évaluation.

## Contenu du dépôt
- **Dossier professionnel** : mes réalisations pour chacune des 8 compétences du titre.
- **Dossier de projet** : InnovShop, de l’analyse du besoin au déploiement.
- **Présentation** : les diapositives de l’oral, en PowerPoint et en PDF imprimable.

## Comment lire les documents

1. Commencer par le **dossier professionnel** pour la vue d’ensemble de ma pratique.
2. Poursuivre avec le **dossier de projet** : conception, architecture, choix techniques, sécurité, tests et mise en ligne.
3. La **présentation** reprend les points clés utilisés pendant l’oral.

## Projet InnovShop

Plateforme e-commerce de produits technologiques, sans paiement en ligne, avec espace client et back-office.

- **Formation** : Titre Professionnel Développeur Web et Web Mobile, Global digital university
